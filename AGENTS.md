# Project guidance

Read `docs/website-handoff.md` before designing or implementing the website. It is the primary source of truth for website design, including visual direction, layout, content hierarchy, navigation, CT progression, expanded reading states, accessibility, and mobile behavior.

Use the original CV in `source-material/` and its text extraction only as content references. Preserve facts, dates, contribution scope, author order, and publication status. Do not derive website styling, layout, or section order from the CV.

Follow later explicit user instructions when they revise the handoff. Track unresolved factual inputs in `docs/content-needs.md`; do not invent missing details.
