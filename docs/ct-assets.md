# CT image provenance

All 34 files in `dist/assets/ct/` are unchanged 512×512 PNG originals from the [Wikimedia Commons collection](https://commons.wikimedia.org/wiki/Category:Computed_tomography_images_of_Mikael_H%C3%A4ggstr%C3%B6m%27s_brain). Each individual file page identifies the license as CC0 1.0. Creator credit: Department of Radiology, Uppsala University Hospital; uploaded by Mikael Häggström.

[The per-file manifest](../dist/assets/ct/manifest.json) records source pages, original URLs, license URLs, dimensions, and hashes. All 34 local files match Wikimedia's published original SHA-1 values. Total image size is 2,748,224 bytes.

Playback uses ascending filename order, from skull base to crown. The source's embedded stack is reversed; its alphabetical category listing is not the playback order. Each image retains its full frame, black margins, and scanner-support outlines. No image has been cropped, mirrored, rotated, resized, recolored, or re-encoded. The common viewport keeps a constant scale across frames.

The source identifies axial CT with intravenous contrast. Anterior at image top and posterior at image bottom are inferred from visible facial anatomy. Patient left/right, slice spacing, and physical pixel spacing have not been established, so no laterality or physical measurements are displayed.

The scan belongs to the reference collection, not Zain. The portfolio uses his name in an OHIF-inspired identity frame as a visual metaphor; image credits explain the external source.
